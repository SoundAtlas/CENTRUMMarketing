# CENTRUM Marketing

A first semester C# console application developed for CENTRUM Marketing.

The system was created as a prototype to improve overview and management of:

- Customers
- Tasks
- Deadlines
- Collaborators

The project was developed using object-oriented programming, layered architecture, repository pattern, JSON persistence, and UML/Larman analysis and design principles.

---

# Features

- Customer management
- Task management
- Collaborator management
- Dashboard overview
- JSON data persistence
- Search functionality
- Task status management
